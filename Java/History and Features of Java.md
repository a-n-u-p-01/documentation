
## 🕰️ History of Java

- **1991** – Java was initiated as a project by **James Gosling**, **Patrick Naughton**, and others at **Sun Microsystems**.
- **Project Name**: *Green Project*.
- **Initial Language Name**: *Oak* (named after an oak tree outside Gosling's office).
- Later renamed to **Java** (inspired by Java coffee from Indonesia).
- **1995** – Officially released as Java 1.0 by Sun Microsystems.
- **2009** – Sun Microsystems acquired by **Oracle Corporation**.
- Java has evolved significantly, with major releases almost every 6 months (as of Java 9+).

### 📅 Key Milestones

| Version       | Year | Major Additions                                     |
| ------------- | ---- | --------------------------------------------------- |
| Java 1.0      | 1995 | First public release                                |
| Java 2 (1.2)  | 1998 | Swing, Collections Framework                        |
| Java 5        | 2004 | Generics, Annotations, Enhanced for-loop            |
| Java 8        | 2014 | Lambda Expressions, Stream API                      |
| Java 9        | 2017 | Module System                                       |
| Java 11 (LTS) | 2018 | New HTTP Client, String enhancements                |
| Java 17 (LTS) | 2021 | Sealed classes, pattern matching                    |
| Java 21 (LTS) | 2023 | Virtual Threads (Project Loom), record patterns     |

> 📌 *LTS = Long-Term Support version*

## ✨ Features of Java

### ✅ Simple
- Easy to learn if you know C/C++
- No complex pointer arithmetic or memory management

### ✅ Object-Oriented
- Everything (except primitives) is an object
- Supports **OOP concepts**: Inheritance, Polymorphism, Encapsulation, Abstraction

### ✅ Platform Independent
- Java code is compiled into **bytecode**, which runs on **JVM**.
- WORA: *Write Once, Run Anywhere*

### ✅ Secure
- No explicit pointers
- Bytecode verifier and sandboxing model
- Strong exception and memory management

### ✅ Robust
- Strong type checking at compile time
- Automatic **garbage collection**
- Handles runtime errors using **exception handling**

### ✅ Multithreaded
- Built-in support via `Thread` class and `Runnable` interface
- Enables concurrent execution of parts of a program

### ✅ Architecture Neutral
- Bytecode runs on any system with JVM, independent of underlying architecture

### ✅ High Performance
- Uses **Just-In-Time (JIT)** compiler to improve runtime performance

### ✅ Distributed
- Supports networking, RMI (Remote Method Invocation), and APIs for building distributed systems

### ✅ Dynamic
- Supports dynamic loading of classes
- Can adapt to evolving environments (reflection, dynamic proxies, etc.)

---

## 🔁 Summary

- Java was designed to be **simple**, **secure**, **robust**, and **portable**.
- Its ecosystem is widely used for **web**, **enterprise**, **mobile**, and **embedded** development.
- Still evolving with modern features like **Lambdas**, **Streams**, **Virtual Threads**, and more.
